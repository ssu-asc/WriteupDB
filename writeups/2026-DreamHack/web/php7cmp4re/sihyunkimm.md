# php7cmp4re

## 문제 설명

> php 7.4로 작성된 페이지입니다. 알맞은 Input 값을 입력하고 플래그를 획득하세요.

- 접근: Dreamhack VM
- 제공 파일: `index.php`, `check.php`, `flag.php`

## 풀이

### 분석

`check.php`의 핵심 조건은 다음과 같다.

```php
if ($input_1 != "" && $input_2 != "") {
    if (strlen($input_1) < 4) {
        if ($input_1 < "8" && $input_1 < "7.A" && $input_1 > "7.9") {
            if (strlen($input_2) < 3 && strlen($input_2) > 1) {
                if ($input_2 < 74 && $input_2 > "74") {
                    echo $flag;
                }
            }
        }
    }
}
```

PHP 비교에서는 피연산자의 타입에 따라 비교 방식이 달라진다.

- 문자열끼리 비교할 때 두 값이 모두 숫자 문자열이 아니면 사전식으로 비교한다.
- 숫자와 문자열을 비교하면 문자열을 숫자로 변환한 뒤 비교한다. 숫자로 시작하지 않는 문자열은 `0`으로 변환된다.

이 차이를 이용해 모든 조건을 동시에 만족하는 입력값을 찾을 수 있다.

### `input1`

`input1`에는 다음 값을 입력한다.

```text
7.:
```

길이는 3이므로 `strlen($input_1) < 4`를 만족한다. 또한 숫자 문자열이 아니므로 각 문자열과 사전식으로 비교된다.

```text
"7.:" < "8"    // 첫 문자 '7'이 '8'보다 작음
"7.:" < "7.A"  // 세 번째 문자 ':'가 'A'보다 작음
"7.:" > "7.9"  // 세 번째 문자 ':'가 '9'보다 큼
```

ASCII 코드에서 `9`는 57, `:`는 58, `A`는 65이므로 `9 < : < A`가 성립한다.

### `input2`

`input2`에는 다음 값을 입력한다.

```text
II
```

길이는 2이므로 `1 < strlen($input_2) < 3`을 만족한다.

```php
$input_2 < 74
```

위 조건은 문자열과 정수의 비교다. PHP 7에서 숫자로 시작하지 않는 `"II"`를 숫자로 변환하면 `0`이 되므로 `0 < 74`가 성립한다.

```php
$input_2 > "74"
```

이번에는 문자열끼리 비교한다. `"II"`는 숫자 문자열이 아니므로 사전식 비교가 이루어지고, 첫 문자 `I`가 `7`보다 크기 때문에 조건을 만족한다.

### 익스플로잇

웹 페이지의 입력란에 다음 값을 제출한다.

```text
input1: 7.:
input2: II
```

두 값이 모든 비교 조건을 통과하면서 페이지에 플래그가 출력된다.
