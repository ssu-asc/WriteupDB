# 문제명

## 문제 설명

> Oops! Someone accidentally sent an important file to a network printer—can you retrieve it from the print server?

## 풀이

### 분석

문제에서는 네트워크 프린터에 실수로 중요한 파일이 전송되었으며, 이를 프린트 서버에서 가져오라고 한다. 서버의 포트는 62919로 주어졌고, 힌트에서 SMB 프로토콜과 smbclient, smbutil을 사용하면 도움이 된다고 되어 있었다. SMB는 네트워크를 통해 다른 컴퓨터의 파일이나 폴더, 프린터 등의 자원에 접근할 수 있도록 해주는 프로토콜이다. 먼저 서버의 포트가 열려 있는지 확인하기 위해 nc -vz mysterious-sea.picoctf.net 62919를 실행했고, Connection ... succeeded!가 출력되어 해당 포트에 정상적으로 연결할 수 있음을 확인했다. 이후 SMB를 이용하기 위해 smbclient를 사용하려 했지만 처음에는 프로그램이 설치되어 있지 않아 sudo apt update와 sudo apt install smbclient를 통해 설치했다. 설치 후 smbclient -L //mysterious-sea.picoctf.net -p 62919를 실행하여 SMB 서버에서 제공하는 공유 목록을 확인했다. 여기서 shares라는 Disk 타입의 공유와 IPC$라는 IPC용 공유가 존재하는 것을 확인했고, 실제 파일이 있을 것으로 생각되는 shares에 접속하기로 했다. smbclient //mysterious-sea.picoctf.net/shares -p 62919 명령으로 shares 공유에 접속한 뒤 ls 명령을 사용해 파일 목록을 확인했다. 그 결과 dummy.txt와 flag.txt가 존재하는 것을 확인했고, 문제의 목표와 파일 이름을 고려하여 flag.txt가 필요한 파일이라고 판단했다. SMB에서 get 명령은 서버의 파일을 로컬 컴퓨터로 다운로드하는 명령이므로 get flag.txt를 실행하여 파일을 가져왔다. 이후 quit으로 SMB 접속을 종료하고 cat flag.txt를 실행하여 다운로드한 파일의 내용을 확인했고, 출력된 문자열을 플래그로 획득할 수 있었다.

### 익스플로잇

먼저 문제에서 제공된 포트 62919가 열려 있는지 확인했다.

nc -vz mysterious-sea.picoctf.net 62919

연결에 성공했으므로 해당 포트로 접근할 수 있음을 확인했다. 문제의 힌트에서 SMB가 중요하다고 했기 때문에 smbclient를 사용했다. 처음에는 smbclient가 설치되어 있지 않아 다음 명령으로 설치했다.

sudo apt update
sudo apt install smbclient

설치 후 -L 옵션을 사용하여 서버의 SMB 공유 목록을 확인했다.

smbclient -L //mysterious-sea.picoctf.net -p 62919

다음과 같은 공유를 확인할 수 있었다.

Sharename       Type      Comment
---------       ----      -------
shares          Disk      Public Share With Guests
IPC$            IPC       IPC Service (Samba 4.19.5-Ubuntu)

shares가 Disk 타입의 공유이므로 실제 파일이 존재할 것으로 생각하여 해당 공유에 접속했다.

smbclient //mysterious-sea.picoctf.net/shares -p 62919

접속 후 ls 명령으로 파일 목록을 확인했다.

ls

그 결과 다음과 같은 파일을 발견했다.

dummy.txt
flag.txt

문제에서 중요한 파일을 찾아야 하므로 flag.txt를 다운로드했다.

get flag.txt

다운로드 후 SMB에서 나와 로컬에 저장된 파일의 내용을 확인했다.

quit
cat flag.txt

## 배운 점

이번 문제를 통해 처음으로 SMB(Server Message Block) 프로토콜과 smbclient를 직접 사용해 보았다. SMB는 네트워크를 통해 다른 컴퓨터의 파일이나 폴더, 프린터 등의 자원을 공유할 수 있는 프로토콜이라는 것을 알게 되었고, 서버에서 제공하는 공유 공간을 Share라고 한다는 것도 배웠다. 또한 smbclient -L을 사용하면 서버에서 제공하는 공유 목록을 확인할 수 있고, smbclient //HOST/SHARE를 이용하면 특정 공유에 접속할 수 있다는 것을 익혔다. 공유에 접속한 뒤에는 ls로 파일 목록을 확인하고 get 명령으로 필요한 파일을 내 컴퓨터로 다운로드할 수 있다는 것도 알게 되었다
