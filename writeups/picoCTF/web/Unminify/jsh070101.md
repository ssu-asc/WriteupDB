# 문제명

## 문제 설명
    
> I don't like scrolling down to read the code of my website, so I've squished it. As a bonus, my pages load faster!"

웹 페이지의 코드가 압축되어 있기 때문에, 이를 확인하여 숨겨진 플래그를 찾는 문제이다. Minify란 HTML, CSS, JavaScript 파일에서 공백과 줄바꿈을 제거하여 파일 크기를 줄이는 작업으로, 코드의 기능은 그대로 유지되지만 사람이 읽기 어려운 형태가 된다. 문제 제목이 Unminify인 것을 보고 압축된 코드를 확인하는 것이 핵심이라는 점을 예상할 수 있었다.

## 풀이

### 분석

먼저 문제에서 제공된 웹사이트에 접속해 보았지만 화면에는 특별한 내용이 보이지 않았다. 문제의 힌트를 확인해 보니 Ctrl + U를 눌러 페이지 소스를 확인해 보라고 되어 있었다. 페이지 소스란 브라우저가 서버로부터 받은 HTML 파일의 원본 내용을 볼 수 있는 기능이다. 웹 CTF에서는 화면에 보이지 않는 정보가 HTML 코드 안에 숨겨져 있는 경우가 많기 때문에 가장 먼저 확인해야 하는 부분이다.

Ctrl + U를 눌러 소스를 확인하니 HTML 코드가 공백과 줄바꿈 없이 한 줄로 작성되어 있었다. 처음에는 읽기 어려웠지만, Minify는 단순히 보기 어렵게 만든 것일 뿐 코드의 기능이나 내용은 변하지 않는다는 점을 알게 되었다. 따라서 코드를 천천히 살펴보면서 picoCTF 문자열이 있는지 확인하므로써 플래그를 찾고자 하였다.

### 취약점

이 문제는 웹사이트의 HTML 소스 코드 안에 플래그를 그대로 포함해 둔 것이 핵심이다. 사용자는 화면에서 해당 내용을 볼 수 없지만, 브라우저는 HTML 파일 전체를 다운로드하기 때문에 페이지 소스를 확인하면 숨겨진 정보도 모두 확인할 수 있다. 즉, 민감한 정보를 HTML 코드에 숨겨 놓았다는 점이 문제의 취약점이다.
