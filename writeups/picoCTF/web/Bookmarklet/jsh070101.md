## 풀이

### 분석

처음에는 Bookmarklet이라는 단어를 처음 봐서 무슨 뜻인지 몰랐다. 문제를 바로 풀기보다는 먼저 힌트를 확인하였다.

힌트 1

A bookmarklet is a bookmark that runs JavaScript instead of loading a webpage.

이 문장을 번역해 보니 Bookmarklet은 웹페이지 주소 대신 JavaScript를 실행하는 북마크라는 의미였다.

평소 북마크는 구글이나 네이버 같은 웹사이트 주소를 저장하는 것만 알고 있었는데, JavaScript 코드도 저장해서 실행할 수 있다는 것을 처음 알게 되었다.

예를 들어 일반 북마크는 다음과 같다.

https://google.com

하지만 Bookmarklet은 다음처럼 생겼다.

javascript:alert("Hello");

즉, 북마크를 클릭하면 웹페이지로 이동하는 것이 아니라 JavaScript가 실행되는 것이다.

힌트 2

What happens when you click a bookmarklet?

이 힌트를 보고 북마클릿을 클릭하면 어떤 일이 일어나는지 생각해 보았다.

정답은 JavaScript 코드가 실행된다는 것이다.

문제에서 제공된 코드도 다음과 같이 시작했다.

javascript:(function() {
    ...
})();

그리고 마지막에는

alert(decryptedFlag);

가 있었다.

alert() 함수는 화면에 작은 알림창을 띄워 내용을 보여주는 JavaScript 함수이다.

즉, 복호화된 결과를 화면에 출력하려는 코드라는 것을 알 수 있었다.

힌트 3

Web browsers have other ways to run JavaScript too.

처음에는 북마크를 직접 만들어야 하는 줄 알았지만, 힌트를 보고 브라우저에서 console 창으로 넣어서 JavaScript를 실행했다.

즉,

Bookmarklet로 실행해도 되고
Console에서 실행해도 같은 결과를 얻을 수 있었다.
코드 분석

문제에서 제공된 코드는 다음과 같은 구조였다.

var encryptedFlag = "...";
var key = "picoctf";

encryptedFlag에는 암호화된 문자열이 저장되어 있었다.

그리고

var key = "picoctf";

를 보니 picoctf라는 문자열을 이용해 복호화를 수행하는 것 같았다.

이 부분이 실제 복호화를 수행하는 코드이다.

decryptedFlag += String.fromCharCode(
    (encryptedFlag.charCodeAt(i)
    - key.charCodeAt(i % key.length)
    + 256) % 256
);

처음에는 어려워 보였지만 하나씩 찾아보면서 이해하였다.

charCodeAt() : 문자를 숫자(아스키 코드)로 바꾼다.
String.fromCharCode() : 숫자를 다시 문자로 바꾼다.
key.charCodeAt(i % key.length) : 키(picoctf)를 반복해서 사용한다.
+256과 %256 : 음수가 되는 것을 방지하기 위한 계산이다.

결국 암호화된 문자열에서 키 값을 빼서 원래 문자열을 복원하는 코드였다.

마지막에는

alert(decryptedFlag);

를 실행하여 복호화된 플래그를 화면에 출력하였다.

코드를 읽어 보면 암호화된 플래그를 복호화한 뒤 그대로 출력하도록 작성되어 있었다.

즉, JavaScript를 실행하기만 하면 플래그를 확인할 수 있었다.
