# 문제명

## 문제 설명

Can you get the flag?

- http://saturn.picoctf.net:63098/

## 풀이

### 분석

문제를 실행하면 간단한 웹페이지가 하나 나타난다. 페이지에는 Includes에 대한 설명과 "Say hello" 버튼만 있어서 처음에는 특별한 부분이 보이지 않았다. 하지만 문제에서 제공한 힌트인 "Is there more code than what the inspector initially shows?"를 보고, 개발자 도구를 이용해 웹페이지의 소스 코드를 자세히 확인해 보기로 했다.

웹 해킹 문제를 처음 풀어보는 입장이라 먼저 인터넷에서 HTML이 어떻게 구성되는지, 개발자 도구는 무엇인지, HTML에서 CSS와 JavaScript 파일을 불러오는 방법 등을 찾아보았다. HTML은 웹페이지의 구조를 만드는 언어이고, CSS는 디자인을 담당하며, JavaScript는 버튼 클릭이나 다양한 기능을 수행하는 프로그래밍 언어라는 것을 알게 되었다.

개발자 도구의 Elements 탭에서 HTML 코드를 확인하던 중 다음과 같은 코드를 발견하였다.

<script src="script.js"></script>

처음에는 <script> 태그가 무엇인지 몰라 검색해 보니, src 속성은 외부 JavaScript 파일을 현재 웹페이지로 불러오는 역할을 한다는 것을 알게 되었다. 즉, 실제 코드가 HTML 안에 있는 것이 아니라 script.js 파일 안에 있을 수도 있다는 의미였다.

### 취약점

이번 문제는 일반적인 웹 취약점을 이용하는 문제가 아니라, 웹페이지에서 함께 불러오는 파일들을 확인하지 않는 사용자의 실수를 이용한 문제라고 볼 수 있다.

웹페이지는 보통 HTML 파일 하나만 사용하는 것이 아니라 CSS, JavaScript 같은 여러 파일을 함께 불러온다. 사용자는 화면에 보이는 내용만 확인하는 경우가 많지만, 개발자 도구를 이용하면 브라우저가 함께 다운로드한 파일들도 확인할 수 있다.

이번 문제에서는 flag를 하나의 파일에 저장하지 않고 CSS 파일과 JavaScript 파일에 나누어 숨겨 두었다. 따라서 HTML만 확인해서는 flag를 얻을 수 없고, 함께 포함된 파일까지 모두 확인해야 한다.

### 익스플로잇

먼저 개발자 도구(F12)를 열고 Elements 탭에서 HTML을 확인하였다.

HTML 코드에서 다음과 같은 부분을 발견하였다.

<script src="script.js"></script>

src="script.js"가 외부 JavaScript 파일을 의미한다는 것을 확인한 후, Sources 탭으로 이동하여 script.js 파일을 열었다.

script.js에는 다음과 같은 코드가 있었다.

function greetings()
{
  alert("This code is in a separate file!");
}

//  f7w_2of2_6edef411}

여기서 //는 주석(Comment) 이라고 한다. 주석은 프로그램이 실행하지 않는 메모이지만, CTF에서는 개발자가 힌트나 flag를 숨겨 두는 경우가 많다는 것을 검색을 통해 알게 되었다.

또한 문자열 안에 2of2라는 문구가 있는 것을 보고, 이것이 flag의 두 번째 조각(2 of 2) 이라는 의미라고 추측하였다.

그러면 첫 번째 조각도 다른 파일에 있을 것이라고 생각하여, 이번에는 HTML과 함께 사용되는 CSS 파일도 확인하기로 하였다.

Sources 탭에서 style.css 파일을 열어보니 다음과 같은 주석이 있었다.

/* picoCTF{1nclu51v17y_1of2_ */

여기에는 1of2라는 문구가 있었고, 이것이 flag의 첫 번째 부분이라는 것을 알 수 있었다.

따라서 두 파일에서 얻은 문자열을 순서대로 이어 붙였다.

첫 번째 조각

picoCTF{1nclu51v17y_1of2_

두 번째 조각

f7w_2of2_6edef411}

이를 합치면 최종 flag를 얻을 수 있었다.

## 배운 점

이번 문제를 통해 웹페이지는 HTML 파일 하나만 사용하는 것이 아니라 CSS와 JavaScript 같은 여러 파일을 함께 불러온다는 것을 처음 알게 되었다. 또한 개발자 도구(F12)의 Elements, Sources 탭을 이용하면 브라우저가 다운로드한 파일들을 직접 확인할 수 있다는 것도 배웠다.

처음에는 HTML만 확인하면 되는 줄 알았지만, 문제 이름인 Includes처럼 다른 파일을 포함해서 사용하는 구조를 이해하는 것이 중요했다. 특히 src는 외부 파일을 불러오는 속성이고, //나 /* ... */ 같은 주석은 프로그램 실행에는 영향을 주지 않지만 CTF에서는 힌트나 flag를 숨기는 장소로 자주 사용된다는 점을 알게 되었다.
