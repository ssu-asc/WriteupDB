# 문제명

## 문제 설명

중요한 정보가 적혀있는 보안 메일을 발견하였습니다.

보안 메일의 비밀번호는 생년월일 6자리인 것으로 파악되나, 저희는 비밀번호 정보를 가지고 있지 않습니다.

비밀번호를 알아내고 보안 메일을 읽어 중요한 정보를 알아내주세요!

- 문제 URL / 파일 등 접속 정보: html 파일

## 풀이

### 분석

문제 페이지에는 중요한 정보가 담긴 보안 메일이 존재하며, 해당 메일의 비밀번호는 생년월일 6자리 형식인 것으로 주어진다. 비밀번호를 알아내면 보안 메일을 열람할 수 있고, 그 안에서 플래그를 확인할 수 있다.

### 취약점

해당 페이지의 비밀번호 검증 로직은 클라이언트 측 JavaScript 코드에 포함되어 있다. 따라서 사용자는 개발자 도구를 통해 검증 함수와 실패 조건을 직접 확인할 수 있다.

또한 비밀번호가 생년월일 6자리라는 제한된 형식을 가지기 때문에 가능한 경우의 수가 매우 작다. 이로 인해 서버 측 검증이나 시도 횟수 제한이 없다면 브라우저 콘솔에서 반복문을 실행하는 것만으로도 올바른 비밀번호를 찾을 수 있다.

결과적으로 이 문제의 핵심 취약점은 클라이언트 측에 검증 로직이 노출되어 있고, 입력값의 탐색 범위가 작아 브루트포스 공격이 가능하다는 점이다.
